# 工作目录确认

在开始任何创作型任务之前,必须先确认文件存放位置,不要擅自决定。

## 步骤

1. **询问用户**工作文件存到哪里,用 AskUserQuestion 给出两个选项:
   - **选项 A:使用已有文件夹** — 可以位于任意盘(D 盘、E 盘等)
   - **选项 B:新建一个文件夹** — 指定盘符和路径,新建存放

2. **选项 A - 已有文件夹**:
   - 查看可用盘符:`ls /`(Git Bash 下 C 盘显示为 `/c`、D 盘为 `/d`、E 盘为 `/e`,以此类推)
   - 请用户给出具体路径(例如 `D:\作品集\小说`),如不确定可列出该盘下的候选文件夹供选择
   - 用 `ls` 验证该文件夹确实存在,存在才继续
   - `cd` 到该目录,确认无权限/路径问题

3. **选项 B - 新建文件夹**:
   - 询问用户:在哪个盘、哪个路径下新建?文件夹叫什么名字?
   - 用 `mkdir -p <路径>` 创建
   - `cd` 到新文件夹

4. **开始任务前,明确告知用户**:「当前工作目录: D:\xxx」,确认无误后再动手创建或写入任何文件。

## 注意

- 目录未确认前,不创建任何文件、不开始内容创作
- 尊重用户选择,不要擅自决定存放位置
- 目录确认后,本次任务的所有文件操作都在该目录下进行
